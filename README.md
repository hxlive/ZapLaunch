# ZapLaunch

**ZapLaunch 是一个按热键呼出的 Windows 快捷启动面板。** 把每个项目常用的程序、文件夹、文档和网址放进一组，打开面板就能点选，也能输入名称或拼音首字母跨组找。

**1.0.0 Beta · Windows 10 / 11 x64**

[快速上手](#快速上手) · [使用场景](#适合怎么用) · [Beta 测试](#beta-测试) · [源码构建](#从源码构建)

## 第一次打开会看到什么

默认面板有「常用」「工具」「网页」三个分组。你可以先在「常用」里点击计算器，也可以切到「网页」后输入 `jsq`，直接从搜索结果打开计算器。加入自己的项目目录后，下次既能从项目分组里点开，也能按名称搜到。

## 适合怎么用

| 场景 | 怎么摆 |
| --- | --- |
| 每天切换几个项目 | 给每个项目建一组，把编辑器、项目目录、需求文档和后台网址放在一起。 |
| 桌面快捷方式越来越多 | 先把最常用的几个拖进面板，再按「工作」「工具」「网页」分组。想保持固定位置就用手动排序，想让高频入口靠前就按使用次数排。 |
| 同一个程序有几种打开方式 | 复制一个现有按钮，分别填写启动参数和工作目录。比如给同一个编辑器留两个入口，各自打开不同项目。 |
| 想从键盘快速打开一个工具 | 用拼音首字母跨组找。每天都要开的工具，可以再给它单独设置一个热键。 |

## 快速上手

1. 获取 Windows 测试包后，解压并运行 `zaplaunch.exe`。也可以按下文从源码构建。
2. 按 `Ctrl + Alt + Space` 呼出面板，或从任务栏托盘菜单选择「显示面板」。
3. 拖入常用文件夹、文件或快捷方式。试着输入 `jsq` 找到「计算器」，按 `Enter` 启动。

| 按键 | 面板中的操作 |
| --- | --- |
| `Ctrl + Alt + Space` | 呼出面板。可在设置中更改。 |
| `Enter` | 启动当前选中的搜索结果。 |
| `Esc` | 启用「Esc 收起面板」时，先清除搜索词，再按一次收起。 |
| `↓` | 搜索框为空且聚焦时，打开运行历史。 |

搜索范围是你已经加入面板的入口。忘了入口在哪一组，可以直接搜名称。

## 功能介绍

### 分组、搜索和历史

在分组栏创建分组，右键分组可改名或调整顺序。入口支持在同组拖动、跨组移动和复制。按名称或使用次数排序时，切回手动排序仍可回到自己的排列。

搜索会跨过当前分组，匹配入口名称、目标路径、拼音首字母或内置别名。比如输入 `jsq` 找计算器，也可用 `notepad.exe` 找记事本。搜索框为空时按方向键下键，可打开运行历史。

### 入口类型和启动方式

| 要打开的内容 | 用法 |
| --- | --- |
| 程序和 Windows 快捷方式 | 从桌面或资源管理器拖入。程序可在按钮属性中设置参数、工作目录和目标窗口状态。 |
| 文档和文件夹 | 拖进当前分组，点击图标即可打开。 |
| 网页 | 新建按钮，在「目标」里填完整网址。可使用网站图标，或自己选 PNG / ICO。 |
| Windows 系统协议 | 可把协议地址作为按钮目标。例如默认「截图」入口使用 `ms-screenclip:`。 |

设置里可选择单击或双击启动、启动后是否收起面板，以及面板是否跟随鼠标位置弹出。呼出热键和每个入口的独立热键都可以调整。

### 外观和配置

面板支持浅色、深色和跟随系统，可调整每行图标数量、显示名称和排序方式。图标优先使用入口自带图标，也可手动替换。

配置保存在本机，设置中可以导出 JSON，程序也会保留最近五份配置备份。换电脑时，先导入配置，再检查目标路径和盘符。导入会替换当前分组和按钮，有需要保留的配置可以先导出。

## Beta 测试

当前目标平台为 Windows 10 / 11 x64。测试包发布后可从仓库的 Releases 获取。手头有源码时，也可以直接按上文构建并试用。

首次测试可以从几件日常操作开始。

1. 用默认热键呼出面板，再用 `Esc` 清除搜索或收起面板。
2. 拖入一个文件夹和一个快捷方式，确认它们能正确打开。
3. 切换分组、试一次拼音搜索，再导出配置留作备份。

## 从源码构建

项目使用 Rust 和 Slint。Windows x64 构建需要 `x86_64-pc-windows-gnu` Rust 工具链，以及 PATH 中的 MinGW-w64 GCC 和 `windres`。也可以运行[构建脚本](app/build.bat)。

```powershell
cd app
cargo build --release --locked
cargo test --workspace --locked
```

可执行文件位于 `app/target/release/zaplaunch.exe`。重新构建前，请先从托盘退出正在运行的同路径程序。

Slint 相关依赖锁定在 1.18.1。升级时需核对项目用于关闭运行时 SVG 解码的 Winit 补丁。[源码结构](app/docs/源码结构.md) · [设计规格](app/docs/设计规格.md)

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `app/crates/zaplaunch` | 应用入口、界面与业务连接、配置写入和图标缓存 |
| `app/crates/zaplaunch-core` | 分组和按钮的数据模型、搜索、配置与备份 |
| `app/crates/zaplaunch-sys` | Windows 托盘、热键、目标启动和系统交互 |
| `app/crates/zaplaunch-ui` | Slint 界面、布局和组件 |

## 配置与网络

配置默认保存在 `%APPDATA%\ZapLaunch\config.json`，缓存和备份也在这个目录。需要独立配置目录时，可用 `zaplaunch.exe --config-dir "<目录>"` 启动。

自动获取网站图标时，ZapLaunch 会向对应站点请求 `/favicon.ico`。也可在按钮属性里手动选择 PNG 或 ICO 图标。
